# Особенности для Claude Code

- **Без субагентов.** Всю работу (реализацию, ревью, исследование) делай сам в текущей сессии — субагенты слишком
  дороги для тарифа владельца проекта. Ревью — по чек-листу раздела 8 AGENTS.md, по диффу ветки.
- **Пайплайн задачи** — 7 шагов из раздела 1 AGENTS.md. Специалистов подключай через Skill на своём шаге:
  1. `analyst` — гриллинг и спека в `docs/specs/`; 2. человек валидирует спеку;
  3. `flutter-developer` / `rust-developer` — код и тесты; 4. `flutter-reviewer` / `rust-reviewer` — ревью;
  5. правки и повторное ревью, **не больше 3 кругов**, на 3-м с замечаниями — спроси человека;
  6. ревью человека + CI; 7. мёрж только по аппруву человека.
  Одну роль за раз: ревьюера подключай, когда разработчик закончил, и сужай контекст до спеки и диффа
  (`git diff main...HEAD`), не опираясь на рассуждения разработки. Спеки и решения — в `docs/`.
- Хуки проекта (`.claude/settings.json`, скрипты в `.claude/hooks/`, нужен `bash` — на Windows Git Bash):
  - после каждой правки `.rs` — `rustfmt` файла и `cargo clippy -D warnings` по его крейту; после правки `.dart` —
    `dart format` и `dart analyze --fatal-infos` по файлу (сгенерированный код пропускается). Ошибки приходят сразу —
    исправляй их сразу, а не в конце задачи;
  - перед командой оболочки — блокируются `--no-verify`, force-push, push в `main` и смена `core.hooksPath`;
    если такое действительно нужно — попроси человека, он выполнит сам;
  - при старте сессии включается `git config core.hooksPath .githooks`, если он ещё не включён.
- Перед коммитом хук `.githooks/pre-commit` гоняет формат, линтеры и тесты затронутой части (Rust / Dart).
  Не обходи его (`--no-verify` запрещён). Файл, добавленный в коммит частично, хук не пропустит — добавь целиком.
- Перед push, удалением, переписыванием истории и любым действием вне ветки задачи — спроси человека.
- Сообщения человеку: коротко, простым языком, один вопрос за раз, с рекомендацией.
- Устройство для QA — Pixel 7 по беспроводной отладке (`adb devices`). Если устройства нет — попроси переподключить,
  не подменяй прогон на устройстве догадками.
