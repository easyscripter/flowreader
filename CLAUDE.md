# Особенности для Claude Code

- **Без субагентов.** Всю работу (реализацию, ревью, исследование) делай сам в текущей сессии — субагенты слишком
  дороги для тарифа владельца проекта. Ревью — по чек-листу раздела 8 AGENTS.md, по диффу ветки.
- Процесс задачи: гриллинг → спека (подтверждает человек) → разбиение → реализация → ревью/QA/исправления → PR.
  Спеки и решения — в `docs/`.
- Хуки проекта (`.claude/settings.json`) после каждой правки `.rs` / `.dart` запускают форматирование и линтер;
  их ошибки нужно исправлять сразу, а не в конце задачи.
- Перед коммитом хук `.githooks/pre-commit` гоняет формат, линтеры и тесты. Не обходи его (`--no-verify` запрещён).
- Перед push, удалением, переписыванием истории и любым действием вне ветки задачи — спроси человека.
- Сообщения человеку: коротко, простым языком, один вопрос за раз, с рекомендацией.
- Устройство для QA — Pixel 7 по беспроводной отладке (`adb devices`). Если устройства нет — попроси переподключить,
  не подменяй прогон на устройстве догадками.
