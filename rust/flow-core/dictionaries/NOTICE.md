# Hyphenation dictionaries

`ru.standard.bincode` and `en-us.standard.bincode` were taken unmodified from
the `hyphenation` crate 0.8.4 (Apache-2.0/MIT). The crate compiled them from
the hyph-utf8 patterns (tex-hyphen commit
49706f9cfa97f6ead26b473ec10d23d5a651318a).
