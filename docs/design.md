# Дизайн UI/UX

Макеты читалки сделаны в Claude Design: дизайн-система, UI-kit под Flutter, флоу, экраны телефона и планшета в светлой и тёмной темах. Это эталон для Flutter-разработчика. UI-задачи блоков 3–7 плана 2 начинаются только после того, как их экраны утверждены.

Артефакт: https://claude.ai/artifact/JbHL4kAqTtNjpwAvMvre7V (приватный, доступ у владельца).

Статус: на утверждении, ни один экран пока не утверждён.

## Дизайн-система

- Темы: светлая, тёмная, сепия, чёрная (для OLED).
- Шрифты: Golos Text для интерфейса, Literata для текста книги, JetBrains Mono для кода. Шкала названа по `TextTheme`.
- Цвета взяты из логотипа: фиолетовый акцент (`#4A3FD0` в светлой теме, `#A99BFF` в тёмной), второй цвет бирюзовый, фон тёмной темы `#0C0F22`.
- Радиусы: обложка 3, контрол 8, диалог 12, лист 14, плавающая кнопка 16. Цель касания 48 dp.
- Компоненты названы по виджетам Flutter (`FilledButton`, `NavigationBar`, `NavigationRail`, `FloatingActionButton.extended`, `ChoiceChip`, `SegmentedButton`, `ListTile`, `AlertDialog`, `SnackBar`), плюс свои `BookCard` и `BookListTile`.
- 34 линейные иконки на сетке 24 dp с именами из `Icons`, иконка приложения.

## Экраны

| Флоу | Экраны | Задача плана 2 |
|---|---|---|
| Первый запуск | заставка, онбординг из 5 шагов (можно пропустить), пустая библиотека | 7, 3.2 |
| Добавление книги | выбор файла или папки, выбор книг из папки, импорт, карточка книги, полное описание, карточка без автора и описания | 4.3, 3.3 |

| Навигация | библиотека, закладки (группы по книгам), настройки приложения | 3.2, 3.4, 6.3 |

Адаптив: малый телефон 360×640, планшет 820×1180 в портрете и 1180×820 в альбомной ориентации. На планшете вместо нижней панели боковая рейка. У каждого экрана есть копия в тёмной теме.

## Решения

- Навигация: на телефоне нижняя панель из трёх пунктов (библиотека, закладки, настройки), на планшете боковая рейка.
- Книга добавляется через плавающую кнопку «Добавить». В листе два пункта: выбрать файл или выбрать папку.
- Долгое нажатие на книгу открывает окно с одной кнопкой «Удалить книгу». Подробности о книге смотрят в карточке.
- Кнопка удаления везде одна и та же: сплошная красная (`error`), в диалоге подтверждения текстовая.
- Экспорта в EPUB нет (решение владельца от 2026-11-11).
- В интерфейсе пишем «конвертация», а не «перекладка».
