# Тема приложения (токены дизайн-системы во Flutter): спека

**Задача плана:** 2.1, последний пункт: «Перенос токенов во Flutter: `lib/ui/core/theme/`» (план 2, задача 2)
**Стек:** Flutter
**Ветка:** `feat/theme`
**Статус:** на валидации у человека

## Цель

Экраны 3.2–7 получают готовую тему, собранную по утверждённой дизайн-системе: цвета, шрифт Golos Text, шкалу
`TextTheme`, отступы, радиусы, размеры и темы стандартных компонентов. Палитры страницы читалки (светлая, тёмная,
сепия, чёрная) лежат в одном месте, а не на каждом экране.

## Источник

Артефакт Claude Design из `docs/design.md`, доски «Обзор и темы» (`Main`), «Типографика» (`type`) и «UI-kit для
Flutter» (`kit`). Человек утвердил их 2026-11-13 вместе с экранами; экраны могут уточняться по ходу UI-задач. Все значения ниже взяты с этих досок,
разработчик сверяет их с этой спекой, артефакт для работы открывать не нужно.

## Границы

В задаче:
- `lib/ui/core/theme/`: две темы приложения (светлая и тёмная), `TextTheme`, `ReaderPalette` (4 палитры
  читалки), константы отступов, радиусов, размеров, темы компонентов из таблицы ниже;
- `lib/utils/window_size_class.dart`: классы окна по ширине;
- шрифт Golos Text (вариативный TTF) в `assets/fonts/golos_text/` с `OFL.txt`, запись в `pubspec.yaml` и README;
- `FusionReflowApp`: `theme`, `darkTheme`, `themeMode: ThemeMode.system` вместо сида indigo;
- в `docs/design.md` отметка: дизайн-система и экраны утверждены 2026-11-13; экраны могут уточняться по ходу
  разработки, а изменение токенов (цвет, шрифт, размер) — это правка темы из этой задачи, не экрана.

Не в задаче (и где это делается):
- выбор темы пользователем (настройка «тема» и палитра читалки) — 6.1 / 6.3; до неё работает `ThemeMode.system`;
- типографика текста книги (кегль 14–32 / 18, интерлиньяж 1,3–2,0 / 1,55, заголовок главы, колонтитул, красная
  строка, выравнивание) — 5.x / 6.1, вместе с рендером страницы;
- шрифт JetBrains Mono — задача читалки, где появятся блоки кода (5.x);
- свои виджеты `BookCard`, `BookListTile` — 3.2; экраны — 3.2 и дальше;
- иконки (34 SVG) и иконка приложения — отдельная задача, когда понадобятся первому экрану (3.2);
- темы `Checkbox`, `ExpansionTile`, `MaterialBanner`, `SearchBar`, индикатор онбординга — на тех экранах, где они
  появятся (3.2, 3.4, 4.3, 7); до тех пор у них значения Material 3 по умолчанию от нашей `ColorScheme`;
- golden-тесты — вместе с экранами, начиная с 3.2.

только у листа и диалога, тональной заливки по высоте нет).

### Палитры читалки (`reader_palette.dart`)

```dart
@immutable
class ReaderPalette {
  const ReaderPalette({required this.pageBackground, required this.pageText, required this.surface,
      required this.surfaceVariant, required this.onSurfaceVariant, required this.outlineVariant,
      required this.accent, required this.onAccent, required this.accentContainer});
  final Color pageBackground; // фон страницы книги
  final Color pageText;       // текст книги
  final Color surface;        // панель управления, оглавление, лист настроек чтения
  final Color surfaceVariant; // чипы, дорожка ползунка
  final Color onSurfaceVariant; // колонтитул, подписи
  final Color outlineVariant; // разделители
  final Color accent;         // ползунок, активный чип, кнопки
  final Color onAccent;
  final Color accentContainer; // фон выбранного чипа / пункта оглавления

  static const light = ReaderPalette(...), dark = ..., sepia = ..., black = ...;
  static const values = [light, dark, sepia, black];
}
```

*Решение аналитика:* обычный неизменяемый класс, не `ThemeExtension`. Палитра читалки выбирается настройкой
независимо от темы приложения (тема тёмная, а палитра сепия), поэтому из `Theme.of` её брать нельзя: читалка
(5.x / 6.1) берёт выбранную константу. Темам приложения сепия и чёрная не нужны (решение человека, Q2).
Поля `light` и `dark` повторяют цвета `ColorScheme`: это разные знания (палитра страницы и тема приложения
меняются по разным причинам), в файле — комментарий «почему не общее».

## Review Focus

- Вариативный шрифт на устройстве: веса 550 и 650 действительно отличаются от 500 и 600 (ось `wght` применяется);
  на скриншоте QA `headlineMedium` не выглядит как синтетический bold.
- Роли `ColorScheme`, которые дизайн не задаёт: нет ли видимых мест с цветами от `fromSeed`, не совпадающих
  по настроению (например, `secondary` у `Radio` или `Checkbox`); если есть — замечание, а не правка спеки.
- `surfaceTint` прозрачный: у `AppBar`, `Card`, `Menu` нет фиолетовой подложки при подъёме.
- Смена системной темы на лету (приложение открыто) — тема меняется без перезапуска.
- Крупный системный масштаб шрифта (200%): кнопки и чипы растут по высоте, а не обрезают текст
  (`minimumSize`, а не фиксированная высота).
- DRY: каждый hex и размер записан один раз; `light` и `dark` собираются одной функцией.

| Вопрос | Решение | Почему |
|---|---|---|
| Утверждена ли дизайн-система | Да: доски «Обзор и темы», «Типографика», «UI-kit» и экраны (человек, 2026-11-13); экраны могут уточняться по ходу разработки | Без утверждённого дизайна задача не стартует |
| Сепия и чёрная | Темы приложения две: светлая и тёмная; сепия и чёрная — только читалка | Решение человека |
| Состав палитры читалки | Страница и хром читалки: 9 полей, 4 палитры | Панель управления на сепии не должна быть голубовато-белой; цвета есть в дизайне |
| Шрифты | Golos Text (вариативный, OFL) сейчас; JetBrains Mono — в 5.x; Literata уже есть | Golos нужен `TextTheme` сейчас; моно ещё ничего не рисует |
| Темы компонентов | Входят (13 тем из таблицы) | Иначе каждый экран повторяет радиус 8 и высоту 48 |
| Тесты | Юнит и виджет: значения, контраст ≥ 4.5, шкала, размеры; без golden | Экранов нет; CI пропускает golden |
| Веса 550 / 650 | `FontWeight(650)`, `FontWeight(550)` | Во Flutter 3.47 `FontWeight` принимает любое значение и ставит ось `wght` (решение аналитика) |
| `ReaderPalette` — класс или `ThemeExtension` | Обычный класс с 4 константами | Палитра выбирается отдельно от темы приложения (решение аналитика) |
| Роли вне дизайна | Один раз из `fromSeed`, в коде литералами; `inverseSurface`, `surfaceTint` заданы явно | Полная схема без рантайм-генерации (решение аналитика) |
| `secondaryContainer` | = `primaryContainer` | Тональная кнопка, выбранный чип и индикатор `NavigationBar` в Material 3 берут `secondaryContainer`, а в дизайне они фиолетовые (решение аналитика) |
| Индикатор `NavigationBar` 60 × 32 | Остаётся размер Material 3 (64 × 32) | Тема не задаёт размер индикатора; 4 dp не стоят своего виджета (решение аналитика) |
| Классы окна | `lib/utils/window_size_class.dart` | Сетка из дизайна; нужна 3.2 для выбора `NavigationBar` / `NavigationRail` (решение аналитика) |
